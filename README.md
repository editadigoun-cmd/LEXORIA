# LEXORIA

LEXORIA is a premium word-search puzzle game for Android and iOS, built with Flutter from a shared Dart codebase.

## Product direction
- Solo campaign with offline play
- Real-time 1v1 multiplayer and asynchronous challenges
- Daily challenges, categories, progression and leaderboards
- Optional rewarded ads; no forced ads during gameplay

## Visual identity
- Midnight navy backgrounds
- Electric violet primary accents
- Turquoise success states
- Gold rewards

## Development
The repository is being initialized. Generate the native Flutter platform folders with:

```bash
flutter create --platforms=android,ios .
flutter pub get
flutter run
```

Build Android: `flutter build appbundle`
Build iOS (requires macOS and Xcode): `flutter build ipa`

## Repository policy
Use `main` as the primary development branch.
